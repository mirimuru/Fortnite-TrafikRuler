# Fortnite利用時の安全方針

## 最優先事項

このプロジェクトは、Fortniteアカウントの安全性を通信振り分け機能より優先します。Epic Games / Easy Anti-Cheatによる個別ソフトウェアの安全性保証はないため、本プロジェクトがBANされないことを保証するものではありません。

## 許可する実装範囲

当面の実装は、Windowsが公開する標準APIを利用した読み取り専用の監視に限定します。

- ネットワークアダプターの状態・送受信バイト数の取得
- OSが公開するTCP接続・UDPエンドポイント情報の参照
- プロセスIDと通信情報の対応付け（取得可能な範囲）
- 通信量・時刻・接続情報のローカル記録とCSV出力

監視対象のプロセスやゲームの動作に介入せず、ゲーム通信の内容も変更しません。

## 実装しない機能

- FortniteプロセスへのDLL注入、コード注入、デバッグ接続
- プロセスメモリの読み書き、ゲームファイル・設定の改変
- Easy Anti-CheatやGameplay Integrity Toolsの停止・回避・改変
- パケットの書き換え、偽装、遮断、保留、再注入
- Fortnite起動中に動作する独自カーネルドライバーやWFPフィルター
- アンチチートとの互換性が確認できない常駐・フック機能

## 通信経路制御について

通信経路の自動変更は、現時点では実装対象外です。Windows標準のルート設定変更であっても、ゲーム通信への影響やEpic側の判断を完全には予測できません。監視結果だけで目的を達成できるかを先に検証します。

将来、経路制御を再検討する場合も、次の条件をすべて満たすまでは実装・有効化しません。

1. Epic Gamesの最新規約・公式案内を再確認する。
2. ゲームプロセスやゲーム通信に介入しない方式であることを技術的に確認する。
3. アカウント安全性への不確実性と、通信断・誤判定のリスクを明示する。
4. 既定では無効とし、ユーザーが明示的に選択できる。
5. いつでも監視専用モードに戻せる。

## ログとプライバシー

通信先IPアドレス、ポート、プロセス情報は利用環境に関する情報です。ログはローカル保存を基本とし、外部送信しません。共有する場合は、IPアドレスやユーザー名などを確認・マスキングしてください。

## 利用上の注意

Epic Gamesはサードパーティーソフトウェアを公式サポートしておらず、特定ソフトの利用がBANにつながるかどうかを個別に判断・開示できないと案内しています。したがって、読み取り専用の監視であってもリスクがゼロとは断言できません。安全性を最優先する場合、Fortnite起動中は本アプリを終了しておく選択が最も保守的です。
